# Noita_Bones_Visualizer
A visualizer for the bones_new file in noita containing the wands that ghosts can spawn with.

The purpose of this is to input the bones_new file located at C:\Users\[USER]\AppData\LocalLow\Nolla_Games_Noita\save00\persistent\bones_new and display what the wand would look like in game by using the in-game spell thumbnails. It will also describe the wand's cast delay and reload speed.
